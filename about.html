INFINITE QUILT

  • About this Project

Web crawlers are automated bots that browse the internet to discover, download, and index webpages, often used by search engines and artificial intelligence. Infinite Quilt repurposes the goal of a web crawler, from optimizing information and ad revenue to perpetually building a never-ending quilt. The web crawler we built for this project maps colors from the images it encounters in its journey across the internet onto traditional quilt blocks (e.g. courthouse steps, pinwheel). It then arranges them according to a set of common quilt patterns (e.g. barn raising, log cabin). These new, computationally generated images are automatically stored in a folder on Box, a software containing seemingly “infinite” storage we access through the university where we teach. The human hand is felt in this project as we help this perpetual web-crawler bring its work into the physical world by selecting a sequence of images it produces to print on watercolor paper, then stitch prints together for environments of various sizes. We have made a short video featuring images made by our web crawler, and will host quilting workshops in which participants quilt against the algorithm using donated pillow cases as quiltable-extensions of their bodies.

This project was created by xtine burrough and Kevin Sweet.
